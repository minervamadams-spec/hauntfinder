Connect your private subscriber sheet

Open the subscriber sheet, then choose Extensions → Apps Script. Replace the starter code with the code below and save.

  1. In Apps Script, open Project Settings. Under Script properties, add CRON_SECRET with the same private value you saved in Vercel.
  2. Choose configureCommunityAlerts from the function dropdown and click Run. Authorize your own script to access this sheet and call your website.
  3. Choose Deploy → New deployment → Web app. Execute as yourself. Set Who has access to Anyone. The sheet stays private; the script only accepts signed requests.
  4. Copy the Web app URL ending in /exec. Save it in Vercel Production as SUBSCRIBER_SHEET_URL.
  5. Tell Minerva’s assistant when this is saved. Keep signup disabled until the connection check and email test pass.

Do not put the API key or CRON_SECRET into the script source or chat. The daily trigger uses New York time and follows daylight-saving changes.
